The text tool protocol

Not every model supports native function calling. For those, agents use a text protocol: the model writes a fenced JSON block, the runtime executes it, and the result is fed back.

{"command": "fetch_financial_statements",
 "args": {"ticker": "SPT", "statements": ["income", "balance", "cashflow"], "periods": 5}

Rules enforced by the runtime: only tools on the agent's allow-list can run; arguments are type-coerced against the tool schema; every call is recorded with success/error; and the model is told it must never claim a source it did not call.

Valuation inputs

The valuation agent derives its inputs deterministically: unit-normalized financials (for example …_millions_usd keys), CAPM cost of equity with stated defaults (risk-free 4.25%, equity risk premium 5.0%, pre-tax cost of debt 7.0%, tax 25%, +1.0% small-cap premium under $2B market cap), peers filtered to 0.1×–10× the target's market cap, a 5-year FCF fade to 2.5% terminal growth. Everything it assumed, retrieved or could not retrieve is stored in an audit object that the UI and reports display.
