Status & limits

An honest account of what has been exercised and what has not.

Verified end to end

  • The interactive chat pipeline: clarify → plan → approve → execute → memo → brief, with real SEC EDGAR and Finnhub data, through an OpenAI-compatible endpoint, on a real company (Sprout Social).
  • Dashboard metrics and per-deal insights, the task board, and generation of all four report formats with the review gate.
  • 448 automated tests (backend), a TypeScript build, and visual checks of the UI and reports.

Implemented but less exercised

  • The LangGraph deal orchestrator, OFAS missions, the debate engine, confidence and user-input gates, HaluGate NLI checks, GP-led CV and LMT workflows. They are in the repository and API-exposed, but the demos and docs here do not claim them as verified.
  • Neo4j as the knowledge-graph backend, the cloud PageIndex mode, and MCP integrations depend on external services.

Known limits

LimitDetail
Redis is requiredThere is no in-memory fallback for deals, conversations and artifacts
Single-tenantNo user accounts; an optional admin bearer token guards report endpoints
Model quality variesChat-style proxy models can return canned errors or off-topic text; these are detected and retried, but output quality still depends on the model
Agents can still disagreeDCF assumptions are shared via the prompt, not forced; disagreement above 15% is flagged for a human, not resolved automatically
Comps are only as good as the peer listFinnhub peers can be loosely related; the valuation agent filters by size and uses the median, but peer selection is not curated
No calibrated confidenceConfidence numbers are model-reported and labelled as such
No deal score in the chat flowReports say "deal not scored" rather than invent one; the memo recommendation is a labelled draft
Run timeA full run with a remote chat-style model takes several minutes; local models vary
US-centric dataSEC EDGAR XBRL covers US filers; other markets need other sources
Windows test failuresTwo tests fail only on Windows (symlink permission, hard-coded paths)

Data and privacy

The site and the app make no calls to analytics services. The app sends prompts and tool outputs to whichever LLM provider you configure, and requests to the data APIs you enable. Run local models and the knowledge base stays on your machine. The demos use public company data only.

Not financial advice

DealForge produces analysis drafts. It is not an investment adviser, and its outputs must be reviewed by qualified people before any decision.
