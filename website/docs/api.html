API reference

The backend exposes about 100 routes under /api/v1. Interactive OpenAPI docs are served at /docs on a running backend. Report-generation, download and approval endpoints honour ADMIN_API_TOKEN (send Authorization: Bearer …) when enforcement is on.

Chat pipeline

MethodPathPurpose
POST/chat/clarifyData-need analysis and clarifying questions (≤3 rounds; user_skipped proceeds)
POST/chat/clarify/feedbackStore Q&A pairs and outcome scores in clarification memory
POST/chat/planCreate the task plan (todo list) for a deal
POST/chat/execute-taskRun one planned task with its assigned agent
POST/chat/respondConversational answer for follow-up questions
POST/scrum/clarify · /scrum/planScrum Master endpoints (same agent, direct)
GET/stream/events/{deal_id}Server-sent events for live progress

Example: drive the chat pipeline with curl

API=http://localhost:8005/api/v1
DEAL=$(uuidgen)

curl -s $API/chat/clarify -H 'content-type: application/json' -d '{"prompt":"Evaluate a take-private of Sprout Social (NASDAQ: SPT). Do not ask clarifying questions.","deal_id":"'$DEAL'"}'
curl -s $API/chat/plan    -H 'content-type: application/json' -d '{"prompt":"…","deal_id":"'$DEAL'"}'
# review the returned todo_list, then approve and run each task:
curl -s -X POST $API/tasks/$LIST_ID/approve
curl -s $API/chat/execute-task -H 'content-type: application/json' \
     -d '{"agent_type":"data_curator","task":"…","deal_id":"'$DEAL'","task_list_id":"'$LIST_ID'","task_id":"'$TASK_ID'"}'

The exact request bodies are visible in the browser network tab and in the interactive /docs page.
