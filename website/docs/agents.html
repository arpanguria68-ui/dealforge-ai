How agents are chosen

  • The Scrum Master (project_manager) picks agents per task when it plans. Focused requests may get one task; broad requests (full diligence, IC prep) get a multi-stage plan.
  • The planner then enforces structure: data collection first, modelling agents after the valuation agent so they share its WACC and growth, synthesis agents last, and the memo depends on everything.
  • An agent running a task receives the upstream results of the tasks it depends on, not the whole conversation.
