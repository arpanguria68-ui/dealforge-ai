What it does

An end-to-end deal workspace: from a one-line brief to a reviewed deliverable, with the reasoning and sources kept visible.

🧭

Plan-first, human-approved

A Scrum Master agent turns a one-line brief into a dependency-ordered task plan. Nothing runs until you approve it; you can edit, add, delete and reorder tasks first.

🤝

29 specialist agents

Financial analysis, valuation, DCF/LBO, legal, risk, red-team, ESG, tax, treasury, integration and more, each with its own tool allow-list.

🔌

39 tools & live data

SEC EDGAR filings, Finnhub, Alpha Vantage, financial_datasets, web search, a DCF/LBO/sensitivity/Monte Carlo toolbox and document builders.

🧮

Shared, sourced valuation inputs

A valuation agent builds WACC, growth and FCF from filings and market data; DCF/LBO agents start from the same assumptions.

🛡️

It checks its own work

Memo figures are traced to recorded evidence, DCFs are compared across agents, broken DCF bridges are recomputed, and unusable model replies are rejected.

📄

Word, PowerPoint, Excel, PDF

Edited reports (not agent dumps) with a football field, evidence tables, source register and a review gate: drafts stay drafts until a reviewer approves.

📊

Pipeline dashboard

Valuation vs market EV, sourcing and tool-call counters, review flags and the exact reconciliation warnings, per deal.

🗂️

RAG with PageIndex

Deal documents become a section tree (no vector DB needed). Hybrid tree + BM25 + dense search, deal-scoped, with optional Laya rerank, plus a knowledge graph that feeds the risk register. How it works

🔁

Any model, your keys

Local-first routing with cloud fallback, Gemini, Claude, OpenAI, Mistral, Groq, OpenRouter, NVIDIA, Vertex, Ollama, LM Studio or any OpenAI-compatible endpoint.

How it works

The chat pipeline is human-in-the-loop by design.

Describe the deal

Type a deal in chat. Optional clarifying questions (max three rounds) can be skipped.

Review the plan

See every task, its agent and priority. Edit, add or reorder.

Approve & run

Agents execute in dependency order and call real tools; progress streams into the chat.

Verify

Figures are matched to evidence, models are reconciled, and disagreements are surfaced.

Read the brief

An executive brief with evidence snapshot, findings, risks and clickable sources.

Release

Generate Word, PowerPoint, Excel and PDF; a reviewer approves them for release.

Trust by design

Agents are fallible. DealForge assumes so and shows its work.

Gate

Approval before execution

The plan is shown first. Execution only starts after an explicit approve.

Check

Evidence-grounded memo

Every figure in the memo is matched against recorded agent output; the grounding score is shown (for example 46 of 51 figures).

Flag

Cross-agent reconciliation

DCFs more than 15% apart, an LBO entering below market value, or a DCF bridge that does not add up are flagged, not hidden.

Repair

Deterministic fallbacks

A missing LBO or a broken DCF bridge is rebuilt from sourced inputs with every assumption listed.

Gate

Reviewer approval for release

Reports download as _DRAFT_not_approved until a reviewer approves them.

Audit

Provenance trail

Tool calls, parameters, responses and timestamps are recorded and exportable per deal.

Run it yourself

Docker Compose brings up the API, the UI and Redis.

git clone https://github.com/arpanguria68-ui/dealforge-ai.git
cd dealforge-ai
cp .env.docker.example .env.docker   # add at least one LLM provider key
docker compose --env-file .env.docker up --build -d
# UI  http://localhost:3000     API  http://localhost:8005/docs

No Docker? See the local setup. The honest list of what is solid and what is experimental is on the status page.
